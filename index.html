🔐 Security Concepts

1. Encryption

Encryption converts readable information into an unreadable format to protect sensitive banking data.

2. Authentication

Authentication verifies the identity of a customer using passwords, OTPs, or biometrics.

3. Two-Factor Authentication (2FA)

2FA adds an extra layer of security by requiring two different forms of verification.

4. Secure Socket Layer / TLS

TLS protects data exchanged between a customer's browser and the bank's website.

5. Fraud Detection

Fraud detection systems identify suspicious transactions and help prevent unauthorized access.

🔑 Security Algorithms

AES (Advanced Encryption Standard)

AES is a symmetric encryption algorithm used to protect sensitive information.

RSA Algorithm

RSA is a public-key cryptographic algorithm used for secure communication and digital signatures.

SHA-256

SHA-256 is a cryptographic hash function used to verify data integrity.

Digital Signatures

Digital signatures help verify the authenticity and integrity of digital messages.
